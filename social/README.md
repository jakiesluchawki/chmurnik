# Social Media Delivery

**Permanent owner bookmark:** https://jakiesluchawki.github.io/chmurnik/assetySM/

All future social-media deliveries must be registered in
`library/catalog.mjs` and visible from this same parent page. Keep individual
campaign galleries, group downloads by format, put the newest campaign first,
and clearly archive superseded variants. Do not make the owner collect a new
bookmark for every pack. See `library/README.md` for the build contract.

Campaigns are copied into GitHub Pages separately from the application bundle.
No automatic posting to social accounts is performed.
